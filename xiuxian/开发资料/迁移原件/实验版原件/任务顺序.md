# 每日任务顺序（v4）

启动后先返回四区角色主界面，通过“境转”确认到凡间，再依次执行下面四组。倒计时收尾也遵循同一区域顺序，只检查未完成项目。

| 阶段 | 依次执行 |
|---|---|
| 1. 凡间 | 签到与抽奖 → 普通练功与已有掌门传功 → 常羊山神游 → 幻海之心钓鱼 |
| 2. 仙界 | 掌门大殿训话 → 全部护法 → 一键课训 → 宗门传功消耗检查（不扣修为）→ 禁地领奖及派遣 → 斗法 → 论剑 → 市肆博戏 → 市场玉盒 → 通天塔每日奖励 → 埋骨地扫荡 → 仙猎 → 降妖寻宝 |
| 3. 虚空 | 仙祠一键指点及玄灵树 → 家族征收 → 丽晶异域夜猎 → 鸿胪台讨伐 → 珍馐坊采购 → 游心塘钓鱼 → 探星禁区检查 |
| 4. 元极（天阙） | 御木园 → 萦云楼同修和领奖 → 朝会殿朝议和领奖 → 燃心灯收取 |

## 天阙细节

- 御木园：有“收获”先收获、确认奖励并重新种植；否则读状态，健康直接退出。红色异常状态按文字选择施肥、除虫或浇水；未知或矛盾状态不猜。只使用当日现有养护次数，每天最多养护一次。健康树不依赖次数识别，不会因计数缺失而报错。
- 萦云楼：先检查是否有旧奖励。没有旧奖励时启动同修，等待约8秒，先领完奖励、确认奖励弹窗后再做下一项。
- 朝会殿：先检查是否有旧奖励；启动朝议后等待约10秒，领取奖励并确认弹窗后再继续。仅“动画结束”不会被当作已领奖。
- 燃心灯：积累愿力大于0才收取，确认归零；0时跳过。

## 识别失败的处理

单纯的页面/按钮识别失败会先关闭已识别弹窗、点击返回，只使用游戏内X和返回按钮，不发送系统返回，最多8层回到任意四区主界面。恢复后只重试当前任务一次；仍失败就记录该项未完成并继续下一项，不无限点击。

涉及消耗结果不明确时，只返回并记录，不盲目重复消耗。游戏退出前台、用户停止或日期跨天时仍立即停止。无法确认主界面时停止，不点击未知确认按钮。

任务顺序不代表等待几小时的神游全部结束后才离开凡间：神游先启动，其他区域接着执行，之后按凡间→仙界→虚空→元极顺序自动收尾。


论剑修复（2026-10-25）：每次匹配后直接挑战第一位，不读取对手或自身战力。只处理现有免费次数，保留战后次数减少的验证，不购买次数。补充论剑选择对手弹窗专用红叉模板与页面关闭规则；恢复时先关闭弹窗，再点击游戏内返回箭头。


断点续做（v4.3）：新增“继续今日”按钮及“继续今日日常”任务。运行全部日常时按账号和北京时间日期原子保存进度；继续时跳过已处理任务，从中断或未完成任务重新检查状态，再执行后续任务。神游、禁地等倒计时收尾列表一并保存。点击“全部日常→开始”也会自动继续当天进度。旧版本尚未保存的运行不能自动还原断点；更新后首次运行开始记录。

仙猎每日上限改为2次，兼容旧版已启动一次的记录；识别游戏剩余次数，第一轮结束后由自动收尾检查并开启第二轮，不购买次数。每轮仍校验75000陨铁、125000木材报价。


探秘流程修复：降妖启动按钮改为识别“寻宝”。魔域、仙猎、降妖连续执行时共用探秘界面，各项关闭子窗口回探秘，最后一项结束后返回仙界。断点续做、倒计时收尾同样适用；异常仍恢复主界面。已通过共用导航、单项返回、部分续做、寻宝按钮及确认流程测试。

暂停与自动续做（v4.4）：普通“全部日常→开始”现在自动读取本角色当天断点，不再清空进度。暂停按钮保留进程与当前位置，当前操作结束后停止后续输入，显示已暂停后点击继续可恢复。识别超时不计暂停时间，游戏内倒计时照常运行。停止或关闭后重新开始仍读取当天任务断点；中断任务重新检查当前状态。

通天塔领奖路线：点击领取奖励后识别每日只能领取一次的提示并点确定，确认今日已领取后返回游历；后续有探秘任务时直接从游历进入探秘，不再往返仙界主界面。已通过确认弹窗、已领取跳过、游历直达探秘及单项执行返回测试。
仙祠指点：一键指点后识别指点确认弹窗并点击确定，确认弹窗关闭并恢复仙祠页面后才记录完成并进入玄灵树；确认失败不记录完成。已通过确认顺序、已完成跳过和失败保留测试。

征收与仙猎倒计时：新征收目标改为太上凰宗，按文字定位并确认选中地点。已有九尾狐宗征收若仍计时则保留，结束后先领奖再选择新地点。征收优先检测倒计时，有倒计时直接退出执行后续任务；自动收尾检查奖励及剩余次数。仙猎启动后识别倒计时即退出，每日最多2次。已通过计时退出、先领奖再切目标及次数上限测试。

夜猎规则更新：滚动到洞天列表底部，按排列顺序选择最新亮色已解锁的四个洞天，排除灰色未解锁按钮。绿色完成则先领奖，正在倒计时则跳过该洞天；可开始时将轮数确认为15，每处每日15次，共60次。逐洞天保存今日进度，不再使用全部洞天合计15次的旧限制；旧版完成标记会重新检查。四处全部检查后返回，倒计时完成后由自动收尾领取奖励。游戏次数或驻扎条件不足时记录并检查下一处。已通过当前OPPO真实截图的亮色/灰色和最新四处识别，以及四处领奖、60次启动、计时跳过、续做不重复的流程测试。
