# 每日助手 v5：视频顺序与页面层级

四个大模块固定为：**人间 → 仙界 → 虚空 → 元极**。
视频内任务按演示先后执行；未出现在视频里的原有任务仍保留在原区域，放在该区域的视频主线之后。
继续当天任务时跳过已处理项，不重置当天次数；每项尚未完成的倒计时仍由自动收尾处理。

## 人间

常羊山神游 → 凡间圣兽预约 → 门派死地闯荡 → 药谷种植收获 → 门派练功与掌门传功 → 门派每日丹药兑换 → 修真免费礼包 → 签到与抽奖 → 幻海之心钓鱼

## 仙界

全部护法 → 一键课训 → 市肆博戏 → 购买玉盒 → 市场参天造化露（1个） → 悟道室每日悟道 → 掌门大殿训话 → 宗门禁地 → 斗法 → 通天塔每日奖励 → 降妖寻宝 → 仙猎 → 魔域埋骨地扫荡 → 小世界探索与事件 → 论剑 → 检查宗门传功

## 虚空

胜境之喻兑换（第一项1个） → 已驻扎洞天夜猎（四处各15次） → 仙祠指点与玄灵树 → 家族征收 → 观星台膜拜 → 夺道奖励、修炼加速与供奉 → 游道每日修炼 → 鸿胪台讨伐 → 珍馐坊采购 → 仙祠一键赠予 → 游心塘钓鱼

## 元极

燃心灯收取 → 萦云楼同修领奖 → 朝会殿朝议领奖 → 御木园状态与收获重种

## 层级规则

- 护法与课训共用弟子院；玉盒与参天造化露共用市场窗口；造化露完成后回宗门地图，切换悟道室、训话与禁地。
- 通天塔领奖并确定后回游历一次，直接进入探秘；降妖、仙猎、魔域共用探秘。
- 胜境兑换后回征程，直接进行夜猎；仙祠、玄灵树、征收等共用仙居入口。
- 珍馐坊采购完成后回仙居一次，进入仙祠赠予，不先退到虚空主界面。
- 观星台、探索奖励和游道共用探星入口；夺道与供奉后进入游道，看到倒计时退出。星界运转和禁区任务均已取消。
- 天阙按最新要求：燃心灯优先 → 同修领奖 → 朝议领奖 → 御木园。四项同属天阙地图，各项之间不回元极主界面。
- 不同一级入口切换时才回对应角色主界面。页面异常才执行有上限的安全恢复。

## 夜猎

1. 扫描“已驻扎”竖条；绿色“完成”表示既有夜猎可领奖。不用亮度、新旧排名或固定最后四格选目标。
2. 每个目标先确认所选洞天名字；完成则领奖，计时中则保留并处理下一处。
3. 可开始时点击最大轮数，实际读到15次才允许开始。
4. 提交前保存预留记录；提交后同时核对倒计时与游戏总次数减少15。
5. 四处每处15次、总计60次；按洞天保存进度，重启或暂停继续不会重复开启。
6. 单处条件不足会记录未完成并继续检查其余洞天；四处全部检查后才退出。
7. 自动收尾检测到完成后逐处领奖。缺次数、缺驻扎弟子或未识别清楚，不会假报完成或购买次数。

## 探星探索奖励与五处供奉

探索内先进入夺道，分别处理“夺道奖励”和“修炼加速”，两项单独保存当天状态。
再分别进入落日城、战争之门、斗技场、传承之地、不灭城，在各自详情内点击“领取供奉”。
地图金色供奉标记仅用于定位，不视为领取成功；第五处需滚动查找。
每处确认领取结果后才记录完成，只回探索页面；五处全部处理后再退出。
中断后只补未确认地点；领取失败不会把整项标记为完成。


小世界更新（2026-10-26）：
